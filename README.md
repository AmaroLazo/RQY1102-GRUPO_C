# Problema: 
El problema que se aborda en este proyecto es acerca de un edificio que tiene problemas en cuanto a lo administrativo o problemas referente a los gastos de este mismo lo que genera inconvenientes hacia los residentes de este mismo por ende aumentan el riesgo impagos y problemas legales, además de afectar la estabilidad financiera del edificio, también puede generar retrasos en las mantenciones y reparaciones esenciales, lo que pone en riesgo la seguridad y el bienestar de los residentes.
